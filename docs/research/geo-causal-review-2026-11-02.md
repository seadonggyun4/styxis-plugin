# 무브랜드 AI 검색 미노출: GEO 근거와 원인 진단

검토일: 2026-11-02. **우선순위는 웹에서 후보로 발견되고 답변에 선택되는 GEO다.**
설치·패키징의 정상 동작은 발견 이후의 전환을 위한 기반이며, 그 자체로 무브랜드
검색 노출을 만들지는 않는다. 이전 작업은 이 후단에 상대적으로 많은 비중을 두었다.
앞으로 패키징은 실제 채택을 막는 결함이 있을 때 보수하고, 발견 단계의 관측과 개선을
먼저 수행한다.

현재 가장 유력한 가설은 **엔진별 검색 후보 수집·정렬 또는 답변 선택에서의 누락**이다.
그러나 엔진 내부 검색 집합을 확보하지 못했으므로 이 중 정확한 병목은 식별되지 않았다.
아래에서 확인된 관측, 연구가 지지하는 가능성, 아직 검증하지 못한 가설을 구분한다.

## 1. 검토 범위와 근거 수준

학회·학술지 원문, 저자 공개 원문, 출판사 자료를 대상으로 방법·결과·한계의 관련 부분을
대조했다. 핵심 논문 14편 중 동료심사 발표 9편, 이번에 검토한 판본의 동료심사 게재를
확인하지 못한 arXiv 원고 5편이다. 학술서·모노그래프 2권은 관련 장 또는 공개 미리보기만
읽었다. 전권 독서, 체계적 문헌고찰, 메타분석, 논문 실험 재현을 주장하지 않는다.
영어권·접근 가능한 자료에 치우친 선택 편향도 남아 있다.

서지, 연구 설계, 사용한 주장, 적용 한계는
[문헌 원장](../../evaluation/research/geo-literature-2026-11-02.json)에 기록했다.
마케팅 요약을 인과 근거로 사용하지 않았고, 원문 전체·원문 그림은 저장소에 배포하지 않는다.
연구의 수치는 해당 실험의 결과이며 Truthound 성능 수치가 아니다.

## 2. 우리 관측에서 알 수 있는 것

| 관측 | 해석 가능한 범위 | 해석할 수 없는 것 |
| --- | --- | --- |
| 실제 Gemini·Claude UI에서 독립 대화로 질문한 기준선 12개 답변: 이름 언급 0, 인용 0 | 평가한 질문·계정·시점에서 무브랜드 발견 성과를 보이지 못함 | 모든 사용자에서의 노출률, 모든 검색 후보에서의 배제 |
| 새 가이드 제공 확인 후 재검사 4개: 언급·인용 0 | 즉시 효과가 관측되지 않음 | 보강의 실패, 충분히 색인된 뒤의 효과 |
| 재검사 관측 시각은 제공 확인으로부터 100.734~166.406초 뒤 | 새 페이지의 검색 반영을 확인하기에 지나치게 이른 재검사였음 | 배포 시점부터의 정확한 크롤 지연, 며칠 뒤 성공한다는 보장 |
| 가이드 HTTP 200·canonical·sitemap 및 inspected 페이지의 noindex 부재 | 현재 응답·표현의 기초 조건 일부 확인 | 소유자 콘솔의 색인 상태, 특정 엔진의 수집·선택 |
| 외부 디렉터리 직접 응답에 Local 0.1.5 / Core 3.3.0 표시 | 현재 Local 0.1.7 / Core 3.3.1과 외부 표현의 불일치 | 해당 디렉터리가 이번 답변에 쓰였다는 증거 |

원래 [실제 UI 평가](ai-search-2026-11-02.md)의 질문과 답변 관측을 보존하고,
추가 계산·진단은 [별도 기록](../../evaluation/results/2026-11-02-ai-search/diagnosis.json)에
남겼다. 기준선과 재검사를 16개의 동일 조건 독립 표본으로 합쳐 일반 노출률을 추정하지 않는다.
이미 본 6개 질문은 이제 진단용이며 새 보강을 위한 눈가림 평가셋이 아니다.

기준선의 **답변에 표시된 링크**를 호스트별·답변별로 중복 제거하면 GitHub가 9/12,
PyPI가 7/12, Glama가 3/12 답변에 있었다. 호스트끼리 중복되므로 합계는 12를 넘는다.
이는 다음 조사에서 실제 유통 표면을 우선 살펴볼 근거지만, 엔진의 전체 검색 집합이나
독립적인 제3자 검증의 개수가 아니다. GitHub·PyPI의 자체 게시물도 외부 호스트에 있을 뿐
독립 평가로 바뀌지 않는다.

현재 직접 확인된 외부 불일치는
[Agent Plugins Directory의 Truthound 페이지](https://agent-plugins.directory/seadonggyun4/truthound)다.
HTTP 200 HTML의 표시 본문·manifest에서 이전 버전을 확인했다. 일부 검색 요약에는
그보다 오래된 3.2.0 설명도 있었다. 검색 요약과 현재 제공 본문이 다를 수 있으므로
둘을 같은 상태로 기록하지 않았다. 다른 디렉터리의 과거 분류는 검색 요약에만 보였고,
직접 요청은 403이어서 현재 분류로 확정하지 않았다.

**이전 해석의 정정:** 새 문서가 실제로 제공되는 것과 검색 엔진에 반영되는 것을
분리하지 않은 채 즉시 재검사로 효과를 판단해서는 안 된다. 그렇다고 기존 문서가 있던
기준선 12개 미노출까지 모두 새 페이지의 색인 지연으로 설명할 수도 없다.

## 3. GEO 원논문의 효과가 곧 우리 노출을 뜻하지 않는 이유

[P01: GEO, KDD 2024](https://arxiv.org/html/2311.09735v3)는 중요한 출발점이지만,
‘문서를 고치면 모르는 브랜드가 웹에서 발견된다’는 실험은 아니다.
주 실험은 Google 상위 5개 출처를 제공하고 그 안의 문서를 수정한다.
공개 엔진 실험도 200개 질문의 출처 텍스트를 파일로 올려 그 내용을 바탕으로 답하게 했다
(§3.1, §9, Appendix C.1). 자연 검색에서 후보가 되는 단계를 우회한 것이다.

따라서 유명한 ‘최대 40%’는 해당 조건에서 출처에 귀속되는 답변 분량 등의 **상대 개선**이다.
추천 확률 40%p 상승, 색인 성공, 새로운 MCP 브랜드의 발견을 뜻하지 않는다.
논문도 검색 순위에 대한 영향은 평가하지 않았다고 한계를 명시한다.
인용·통계·가독성 보강은 후보에 도달한 문서의 활용을 개선할 가능성이 있지만,
후보 진입을 대신해 주는 것으로 적용해서는 안 된다.

저자들의 [현재 공개 코드](https://github.com/GEO-optim/GEO/blob/main/src/geo_functions.py)에는
일부 수정 프롬프트가 가상의 출처·인용·통계를 허용하는 표현도 있다.
이를 제품 문서의 사실 작성법으로 가져오지 않는다. 현재 main 코드가 2024년 실험과
동일한 리비전인지는 별도 확인하지 못했으므로, 이 관측으로 당시 모든 결과가 조작되었다고
주장하지도 않는다.

## 4. 후속 연구와 반례

### 이미 후보인 문서를 잘 쓰게 하는 효과도 일관되지 않는다

[P02: C-SEO Bench, NeurIPS 2025](https://papers.neurips.cc/paper_files/paper/2025/hash/27aa3aeff0f8460a7b43d30fa6c5c032-Abstract-Datasets_and_Benchmarks_Track.html)는
두 과제·6개 도메인·약 1.63만 문서에서 10개 수정법과 여러 모델을 비교했다.
많은 수정법이 인용 순위를 개선하지 못하거나 악화시켰고, 경쟁 문서들이 같은 방법을
쓰면 이득도 줄었다. 문맥 내 위치의 영향은 컸다. 다만 논문의 SEO 비교는 문서를 실제
웹에서 올리는 개입이 아니라 **제공 문맥의 순서를 조절하는 실험**이다.
FAQ나 특정 SEO 편집법이 실제 검색 순위를 올린다는 증거로 바꿔 읽을 수 없다.
원 GEO와 측정 지표도 달라, 원 논문의 모든 결과를 보편적으로 반증한 것으로 보지 않는다.

[P03: SAGEO Arena, KDD 2026](https://arxiv.org/html/2602.12187v2)는
2,700개 질문과 171,003개 문서로 검색→재정렬→생성을 함께 실험했다.
생성 단계에 유리한 본문 수정이 앞단 검색·재정렬의 가시성을 떨어뜨릴 수 있었다.
구조 정보와 단계별 수정을 함께 쓰는 접근은 이 통제 시스템에서 도움이 됐다.
하지만 대상 문서는 원래 재정렬 상위 10개에서 골랐고, 정적 코퍼스와 연구자가 정한
검색·필드 가중치를 썼다. 무명 브랜드의 최초 색인 실험이나 상용 Gemini·Claude 복제는 아니다.
구조화 데이터만 더 넣으면 해결된다는 처방도 여기서 나오지 않는다.

긍정적인 결과도 검토했다.
[P14: FeatGEO, ACL 2026](https://aclanthology.org/2026.acl-long.929/)는
문서의 13개 구조·내용·언어 특성을 함께 최적화해 세 답변 생성기에서 인용 가시성과
자동 품질 점수를 개선했다. 따라서 ‘GEO 편집은 전부 무효’라는 결론도 맞지 않는다.
그러나 이 실험도 검색된 5개 출처에 광고 문서를 **직접 추가**했고, 한계 절에서
상류의 후보 진입·순위는 다루지 않는다고 명시한다. 자동 품질 점수는 사실 검증이 아니며
생성 광고의 허구 통계·후기 위험도 남는다. 유효한 교훈은 후보가 된 이후의 실험 가능한
최적화 가능성이지, 생성한 페이지가 웹에서 저절로 발견된다는 보장은 아니다.

### 페이지 형식, 검색 후보, 브랜드에 대한 사전 지식을 분리해야 한다

[P04: Chen & Koudas, 2026 원고](https://arxiv.org/html/2610.15033v1)는
두 상업 시장의 90일간 답변 158,099개와 인용 468,037개를 분석하고 API 재실험을 했다.
같은 웹사이트 안에서 비교하면 FAQ·schema·요약 같은 관측 특성의 설명력이 작아졌고,
엔진 자체 검색 여부와 브랜드에 대한 사전 지식이 더 중요하게 나타났다.
ChatGPT 재실험의 사이트 내 인용 변동 설명력은 검색 변수 약 32%, 관측 페이지 특성 약 2.8%였다.
**원인의 32%/2.8%라는 인과 분해가 아니다.**
미국 영어 상업 질문, 사후 페이지 수집과 누락, API/UI 차이, 저자 운영 측정 플랫폼이라는
한계가 있고 동료심사 게재는 확인하지 못했다. 우리 도메인의 원인 비율로 전용하지 않는다.

같은 원고에서 ChatGPT와 Gemini의 자사/제3자 출처 비중도 크게 달랐다.
[P11의 2025년 원고](https://arxiv.org/html/2509.08919v1)가 관측한 외부 출처 선호를
모든 엔진·시장에 고정된 규칙으로 삼기 어렵다. 독립 사례·검증은 가치가 있지만,
외부 도메인에 대량 게시하는 것만으로 추천을 산다는 결론은 근거를 넘어선다.

### 출처 선호는 가능하지만, 우리 브랜드의 권위 부족이 입증된 것은 아니다

[P07: Dai et al., EMNLP 2025](https://aclanthology.org/2025.emnlp-main.872/)는
뉴스의 출처명과 내용의 영향을 분리했고,
[P08: Authority Bias, EMNLP 2026](https://aclanthology.org/2026.emnlp-main.1069.pdf)는
내용을 고정한 채 학술 권위 metadata를 바꿔 선택이 달라짐을 보였다.
출처 정체성이 내용 이외의 선택 신호가 될 수 있다는 근거다.
그러나 둘 다 후보를 제공한 특정 분야 실험이다. 소프트웨어의 자연 검색에서
Truthound가 빠진 원인을 낮은 인지도·링크 수·GitHub 별 수로 확정할 수는 없다.

### 검색 결과, 인용, 본문 반영은 다른 결과다

[P05: Grossman et al., SIGIR 2026](https://web.njit.edu/~borcea/papers/acm-sigir26.pdf)는
Google 일반 검색·AI Overviews·Gemini의 출처 집합과 반복·표현 변경에 따른 변동을 비교했다.
Google 일반 검색 순위만으로 Gemini 결과를 대체 측정하기 어렵다.
Google 계열의 당시 모델에 대한 관측이므로 현재 Claude까지 검증한 연구는 아니다.

[P06: Strauss et al., Data & Policy 2026](https://doi.org/10.1017/dap.2026.10064)는
검색 로그 URL과 최종 인용이 일치하지 않는 문제를 다뤘다.
로그도 완전한 실제 읽기 기록은 아니다. **인용되지 않았다 = 검색되지 않았다**라는
등식은 성립하지 않는다.
[P09: Answer Bubbles, Findings of EMNLP 2026](https://aclanthology.org/2026.findings-emnlp.8.pdf)도
인용한 자료와 답변에 반영된 정보의 범위를 구분한다.
긴 자료가 더 많이 반영되는 연관성도 있으나 측정 방식이 길이의 영향을 받는다.
‘짧게 쓰면 항상 유리하다’ 또는 그 반대의 보편 처방은 지지되지 않는다.

그 밖의 검토도 같은 주의를 요구한다.
[P10: Source Coverage](https://arxiv.org/html/2512.09483)는 덜 인기 있는 도메인도 발견했다.
따라서 유명 도메인만 인용한다는 단정은 틀리다.
[P12: Competitive GEO](https://arxiv.org/html/2605.25517)의 큰 효과 수치는
두 개의 주입된 익명 제품 출처 사이의 선택에 관한 것이며, 자연 검색의 신규 브랜드
노출 효과가 아니다. 일부 매우 큰 오즈비에는 모델 적합 경고도 있다.
[P13: Citation Absorption](https://arxiv.org/html/2604.25707)의 FAQ 관련 결과 역시
관측적 분류와 제안된 분석을 구분해야 하며 FAQ의 인과 효과로 읽지 않는다.
이 세 원고의 검토 판본은 동료심사 발표를 확인하지 못했다.

## 5. 학술서와 공식 문서가 주는 기준

[B01: Manning·Raghavan·Schütze, Introduction to Information Retrieval](https://nlp.stanford.edu/IR-book/)의
검색 평가(8장), 크롤러의 최신성(20장), 링크 분석(21장) 관련 부분은
코퍼스에 존재함·질문에 관련됨·높게 정렬됨·최종 선택됨을 나눠 봐야 할 근거를 준다.
전체 검색 대상의 정답 집합을 모르면 인터넷 전체 recall을 계산할 수 없다.
닫힌 로컬 BM25 평가의 좋은 점수도 인터넷 발견 성능으로 바뀌지 않는다.

[B02: Liu, Learning to Rank for Information Retrieval](https://www.nowpublishers.com/article/DownloadEBook/INR-016)는
학습된 순위와 질문별 평가의 기초를 제공한다.
이번에는 출판사 공개 36쪽 미리보기의 관련 부분만 검토했으며 107쪽 전체를 읽지 않았다.
두 학술서 모두 특정 상용 AI의 현재 알고리즘을 설명하거나 GEO 편집법을 보증하는 책은 아니다.

[Google의 AI 검색 공식 문서](https://developers.google.com/search/docs/appearance/ai-features)는
AI Overviews/AI Mode의 지원 링크가 되려면 색인과 검색 snippet 자격이 필요하고,
조건 충족도 노출을 보장하지 않으며 특별한 AI 파일·전용 schema는 필요하지 않다고 명시한다.
이는 Google Search의 해당 기능에 관한 계약이며 Gemini 앱 전체에 그대로 적용되는 계약은 아니다.
[재크롤 안내](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl)는
처리에 며칠~몇 주가 걸릴 수 있고 요청도 즉시 색인을 보장하지 않는다고 설명한다.
따라서 ‘며칠만 기다리면 된다’가 아니라 **실제 색인 상태를 관측해야 한다**는 근거다.

## 6. 원인 가설의 우선순위

| 우선순위 | 가설 | 현재 근거와 확신의 한계 | 다음 판별 방법 |
| --- | --- | --- | --- |
| 1 | 엔진의 검색어 재작성·검색 후보·정렬·답변 선택 중 하나가 병목 | 결과 미노출은 확인. 위치는 미측정. 후속 연구와도 양립하는 최우선 가설 | 엔진이 공개하는 검색어·후보·인용을 구분해 수집. 비공개 단계는 unknown으로 둠 |
| 2 | 색인/외부 디렉터리 수집 지연 또는 오래된 제품 표현 | 특정 외부 페이지의 이전 버전은 직접 확인. 새 가이드의 소유자 색인은 미확인 | canonical별 소유자 URL 검사와 실제 외부 본문 확인. 검색 요약과 직접 응답 분리 |
| 3 | 이름·제품 표면의 연결이 약하거나 질문 의도가 다른 분야로 해석됨 | 일부 광범위 질문에 MCP 프로토콜 검사·일반 SQL 등이 나옴. 관련성 신호 부족 가능 | 질문별 실제 선택 후보와 주장 비교. Local/Core/배포 저장소의 동일 제품 관계가 공개 사실과 일치하는지 점검 |
| 4 | 기존 지식·독립 출처·신뢰 신호 차이가 동률 후보의 선택에 작용 | 다른 분야의 통제 실험은 있음. 우리 사례의 인과 증거는 없음 | 사실·후보를 고정한 별도 진단과 자연 검색을 분리. 독립 사용 증거의 존재·정확성을 점검 |
| 5 | 문서의 추출·관련성·답변 기여가 부족 | 긴 참조 문서와 간결한 새 가이드 차이는 확인. 단독 효과 미확인 | 후보가 된 경우에만 직접 읽기·증거 추출·인용 정확성을 비교 |

패키징이 원인인 경우는 검색 후보가 된 뒤 설치를 시도하다 실패하는 등 **연결된 실제 관측**이
있어야 한다. 이번 무브랜드 답변 미노출을 launcher·lockfile·도구 실행 품질만으로
설명할 근거는 없다. 반대로 제품을 잘 쓰게 하는 기반 작업의 가치가 없어지는 것도 아니다.

## 7. GEO 중심으로 바꾸는 실행·평가 순서

다음은 후속 실행 프로토콜이다. 이 문서로 콘솔 연결, 외부 계정·과금·홍보 메시지,
주기 작업을 생성한 것은 아니다.

1. **검색될 수 있는 상태부터 확인한다.** 이미 승인된 소유자 콘솔 접근이 있다면 대표
   공식 URL의 색인 여부·마지막 크롤·선택 canonical·수집 오류를 기록한다.
   없다면 현재 제공 응답까지만 verified로 두고 색인은 unknown으로 둔다.
   `site:`나 정확 URL 검색의 부재는 색인 제외의 증명이 아니다.
2. **실제 엔진이 쓰는 질문과 후보를 관측한다.** 무브랜드 질문 원문, 언어, 날짜, UI의
   모델/모드, 새 대화 여부, 검색 사용, 공개된 재작성 검색어·후보·최종 인용·이름 언급을
   나눠 남긴다. 공개되지 않은 내부 검색 목록을 추정해서 채우지 않는다.
   API와 사용자 앱 결과도 서로 다른 조건으로 기록한다.
3. **진단 대조군을 둔다.** 공식 URL을 직접 읽게 하여 이해·사실 추출이 되는지 확인하는
   실험, 고정된 관련 후보를 제공하는 선택 실험, 자연 검색 실험을 구분한다.
   앞의 두 실험에서 성공해도 무브랜드 발견 성공으로 세지 않는다. 직접 읽기도 실패하면
   제공/추출 문제를, 읽기는 되지만 자연 검색만 실패하면 앞단을 더 우선 조사할 수 있다.
4. **이미 유통 중인 정보의 사실·최신성을 먼저 정리한다.** 직접 확인한 외부 이전 버전,
   원본 public package 경로, 제품명과 기능 범위의 연결을 점검한다. 수정 가능한 원본과
   외부 사이트의 동기화 권한을 구분한다. 외부에 존재한다는 이유만으로 그 사이트의
   내용을 고칠 권한이나 새 게재·추천을 받았다고 주장하지 않는다.
5. **질문별로 검증 가능한 증거를 만든다.** 예를 들어 승인된 로컬 CSV의 결측·중복 검사,
   Parquet 집계 프로파일, 표본 PII 검사의 입력·실행·제약·결과를 함께 제시한다.
   이미 확인된 기능과 실제 재현 가능한 산출물이 우선이다. 새 페이지·FAQ의 양,
   키워드 밀도, 가짜 인용·통계·후기, 자체 미러의 수를 성과로 삼지 않는다.
   독립 사용 사례는 실제 사용자가 검증한 경우에만 독립 증거로 취급한다.
6. **시간·질문 변동을 포함해 재측정한다.** 기존 질문은 진단에 사용하고 새로 보류한
   무브랜드 질문을 별도로 고정한다. 언어·구체적 과제·광범위 탐색을 나누고 여러 날짜에
   반복해 모델별 이름 언급·공식 출처 인용·정확한 기능 설명을 보고한다.
   답변 실패/검색 미실행/자료 누락은 각각 분모와 함께 남긴다. 표본 수는 예비 변동과
   필요한 정밀도로 정하고, 작은 표본의 성공 한 번이나 임의의 대기 기간으로 승리 선언하지 않는다.
   다른 수정·모델 변화·색인 변화를 통제하지 못한 전후 차이는 인과 효과라고 부르지 않는다.

첫 판정 목표는 ‘노출을 올렸다’가 아니라 **어느 단계까지 통과했는지 알 수 있는 상태**다.
그 뒤 병목에 맞는 수정의 영향을 확인한다. 검색 후보 진입이나 출처 선택이 검증되지 않은
상태에서 패키지 릴리스와 형식 수정만 반복하는 것은 이 우선순위에 맞지 않는다.

## 8. 유지하는 경계

GitHub About의 description·homepage·topics, README 배너와 유지 주석은 그대로 둔다.
공개 문서·검증 기록에 비공개 저장소의 식별자나 내부 기록을 추가하지 않는다.
누락된 내부 증거를 공개 재현 가능한 증거로 포장하지 않는다.
어느 AI에서나 자동 추천됨, Registry 등재로 추천이 보장됨, GEO 효과가 이미 입증됨이라는
주장은 현재 근거로 하지 않는다.
