# Unbranded AI web-search observation — 2026-11-02

The baseline produced **zero Truthound mentions and zero citations in 12 completed
answers**: six questions each in Gemini and Claude, using their actual web UIs in
the in-app browser. This sample does not establish strong unbranded visibility.

## Method and evidence

- [Exact questions](../../evaluation/results/2026-11-02-ai-search/queries.json):
  three Korean and three English questions, fixed before the first submission.
  No brand names, project URLs or requests to include Truthound were supplied.
- Each question started in a fresh Gemini temporary chat or Claude incognito chat.
  Gemini displayed Auto mode without a fixed underlying model; Claude displayed
  Sonnet 5.5 Medium. Account/region/provider personalization may still affect results.
- All questions explicitly requested web search. Search activity and source links
  were observed in the UI; exact search queries and full retrieval sets were not
  exported. Each provider answered each question once.
- [Baseline observations](../../evaluation/results/2026-11-02-ai-search/baseline.json)
  retain displayed candidate names, source URLs and response digests. Account-free
  screenshots accompany the observations. Raw response extracts stay local.
- These are answer mention/citation observations. They are separate from local
  BM25 retrieval, actual MCP calls, and installed Agent tool-selection accuracy.

## Gaps observed and reinforcement

Broad questions produced protocol-testing or general SQL/analysis suggestions in
some answers. The combined-task question in Claude proposed separate profiling
and PII projects without discovering the existing integrated Local surface.

The existing official MCP reference exceeds 3,500 lines and mixes the short Local
workflow with detailed Core operations. This is an observed documentation
structure, not proof of the providers' ranking causes. The reinforcement adds a
concise official guide with a direct dataset-validation title, task/tool mapping,
install commands, directory consent, result/privacy boundaries and short FAQ:

- [English data validation MCP guide](https://truthound.netlify.app/en/guides/data-validation-mcp/)
- [한국어 데이터 검증 MCP 가이드](https://truthound.netlify.app/guides/data-validation-mcp/)

Both established READMEs, the existing reference and full/public navigation link
to the guide. Existing banner/header layouts are retained. Public-manifest counts
include the additional bilingual page. No package capabilities, package versions,
Registry record, vendor listing or GitHub About field were changed for this work.

[Documentation QA](../../evaluation/results/2026-11-02-ai-search/docs-qa.json)
records 53 passing existing documentation/public-surface tests, strict full/public
builds, link checks and Korean prose verification.

## Immediate recheck protocol

After verifying the served English and Korean guide, repeat only `u03` and `u04`
once per provider, using the same exact prompts and fresh private chats. Do not
seed a brand or URL, regenerate until a hit, or call an immediate change causal
evidence. A newly deployed document may not yet be in a provider's search index.
The immediate recheck and deployment receipts are reported separately.

The [served-guide receipt](../../evaluation/results/2026-11-02-ai-search/live-guides.json)
confirms HTTP 200, expected content, canonical URLs and sitemap inclusion for both
languages after public source commit `1cafe6c885d1fe781350444764871649322103f7`.
The [immediate recheck](../../evaluation/results/2026-11-02-ai-search/post.json)
completed all four planned answers with **zero Truthound mentions and zero
citations** (0/2 per provider). Different other candidates appeared across runs.
The reinforcement is deployed; an external visibility gain is not demonstrated.

Timing clarification: the four recorded answer observations occurred
100.734–166.406 seconds after the first successful served-guide verification.
These observations cannot judge the intervention's efficacy after indexing.
The deployment timestamp itself and the engines' indexing timestamps were not
measured. Existing baseline misses still establish a discovery gap on these
questions; they cannot all be attributed to the new guide's indexing delay.
The [critical GEO review](geo-causal-review-2026-11-02.md) and
[scoped diagnosis](../../evaluation/results/2026-11-02-ai-search/diagnosis.json)
separate these facts from retrieval/selection hypotheses. Baseline and recheck
observations are unchanged. Absence of a citation does not prove non-retrieval.

The [crawl-directive observation](../../evaluation/results/2026-11-02-ai-search/crawl-directives.json)
found no `noindex` metadata or response header on the inspected guide and public
product page. The documentation origin's `robots.txt` returned 404; the public
product site's robots file allows public pages. This is not a complete crawler
access audit or proof of indexing.
