## Retrieval results and limitations

Exact current metrics and per-query failures are in `evaluation/results`. These
are BM25 measurements over **17 curated server/plugin sketches and 19 tool
sketches**, not actual Registry rankings or model selection. All 70 cases run;
40 positive cases form recall/nDCG denominators. Negative exposure is reported
separately from an explicitly observed false selection. No external selection
was observed, so correct-/false-selection rates remain null.

The first rewrite replaced user verbs with narrow technical synonyms. Plugin
Recall@5 fell from .725 to .525 despite improved MRR. Adding supported user-task
verbs and one concise Korean sentence raised it to .95, with Korean recall .90.
The rejected variant is retained. Negative-query target exposure also rose from
.333 to .567 in plugin top-5, and from .233 to .633 in source tool top-3. This
is a material precision warning: broader language and negated task terms improve
recall while increasing lexical matches to unsuitable tasks. It is not measured
false selection; actual client abstention/selection is still required before
claiming improved overall recommendation quality. These fixtures informed the rewrite; the
holdout slice was inspected and is not a blind generalization estimate.

Server metadata describes what package to consider. Tool metadata describes what
to do after connection. For example, q001 (“Check this CSV for missing values and
duplicate rows”) targets `truthound` then `check_file`; q003 Parquet preparation
targets `profile_file`; q006 Korean PII preparation targets `scan_pii`. q066/q067
custom schema cases are hard negatives for this Local surface. Successful E2E
then tests actual selection-compatible arguments and permission behavior; ranked
fixtures alone cannot establish the client's tool choice.

A pipeline-wide conversion rate would require linked real discovery→install→call
traces. Do not multiply unrelated local retrieval and single-install rates. The
reported 1/1 execution receipt verifies one macOS/CLI run, not multi-client
reliability or a formal proof of privacy for every dataset.
