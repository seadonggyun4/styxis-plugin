# Security reporting

Report suspected catalog/source-pin/install vulnerabilities to the public package
maintainer at **seadonggyun4@gmail.com** with affected commit, client/version and a
minimal synthetic reproduction. Use GitHub private vulnerability reporting when
available. Do not attach credentials, private datasets or raw PII to public issues.

Truthound runtime and data-permission defects belong in its
[source security policy](https://github.com/seadonggyun4/Truthound/blob/main/SECURITY.md).
This catalog ships no data-quality implementation. Maintenance is best effort for
the latest catalog pin; no response-time SLA or vendor certification is promised.

A fix should identify affected and replacement source commits, validate actual
installation and permission behavior, and document migration/revocation steps.
